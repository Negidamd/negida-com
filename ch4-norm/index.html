Cholinergic Nucleus 4 (Ch4) Normative Calculator

Convert an individual’s Ch4 gray-matter volume into a normative W-score — how far it deviates from the volume expected in cognitively healthy adults of the same age, sex, and head size — and see where the individual falls within the clinically normal reference distribution.

Research demonstrator · runs entirely in your browser
Research and educational use only. This is a demonstration of a published normative model. It is not a medical device, is not validated for clinical use, and must not be used for diagnosis or patient management. A valid W-score requires Ch4 gray-matter volume measured with the same imaging pipeline as the study (see Required imaging pipeline below). The model was calibrated by cross-validation and has not yet been externally validated. All values are computed locally — no data is transmitted or stored.

Required imaging pipeline for a valid W-score

The W-score is only meaningful if Ch4 gray-matter volume is measured exactly as in the study. A value from a different atlas, threshold, or software package is not comparable and will give a misleading result.

  1. Segmentation. Segment the T1-weighted volumetric scan with CAT12 v12.9 (r2577) running under SPM25 (MATLAB R2023b), using the default preprocessing pipeline including surface estimation.
  2. Ch4 localization. Localize Ch4 with the histology-derived JulichBrain magnocellular basal-forebrain probabilistic atlas, using its maximum-probability map at a 50% tissue-assignment probability threshold.
  3. Gray-matter volume. Within the Ch4 region, compute gray-matter volume by partial-volume integration of the CAT12 gray-matter tissue-probability map — each voxel contributes in proportion to its estimated gray-matter content, not counted as all-or-nothing — reported in millilitres (mL). This is the value entered above.
  4. Head size. Take total intracranial volume (TIV) from the CAT12 subject measures, in mL.
  5. Acquisition site. The model carried a site random intercept; for a scan from a site not in the training sample this intercept is set to zero — the calculator already does this, so no site input is needed.

Atlas: Zaborszky et al., NeuroImage 2008 (JulichBrain magnocellular basal-forebrain maps). Full details are in the study Methods.

Model. Two-stage location–scale normative model of Ch4 gray-matter volume fitted in 5,501 clinically normal participants across 132 acquisition sites. Location: predicted = 0.13987 + 0.00055331·age − 1.1925×10⁻⁵·age² + 0.0034362·[male] + 9.5170×10⁻⁵·TIV. Scale: σ(age, sex) = 1.88736 · exp(−4.85588 + 0.0060783·age + 0.12570·[male]). W = (observed − predicted) / σ(age, sex). For a scanner site not in the training sample, the site random intercept is set to zero (as here) and the denominator is not widened to acknowledge that, so a W-score computed for a scanner that contributed no reference participants should be treated as provisional until that centre’s own clinically normal participants have been scored. Holding out entire sites in the study moved the proportion below the threshold from 5.56% to 6.54%. Coefficients are Supplementary Table S3 of the study.
